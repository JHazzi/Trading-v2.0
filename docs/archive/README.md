# Documentation Archive

Files here are historical.

They may contain commands, assumptions and next steps that were correct for an older package but are no longer current.

Do not use this directory to determine the current roadmap.

Start with:

```text
README.md
ARCHITECTURE.md
AGENTS.md
docs/INDEX.md
docs/RESEARCH_STATUS.md
docs/ROADMAP.md
```

Archive categories:

- `package-notes/` — old root/package/fix READMEs;
- `research-history/` — old research plans/decisions;
- `pre-restructure/` — copies of files replaced during major documentation cleanup.
